全局快捷键

浏览器在后台、游戏在前台时也有效，不会抢走焦点。

如果快捷键没有反应，通常是被其他软件占用了。请点“修改快捷键”，在浏览器设置里换一个组合。

使用方法

  1. 在浏览器打开B站攻略视频，先手动点一次播放。
  2. 切回原神，让游戏保持前台。
  3. 按快捷键：播放 / 暂停、快退、快进，不会切出游戏。
  4. 如果刚安装扩展时B站页面已经开着，刷新一次该页面即可。
建议：保留默认的 Ctrl + Shift + 数字，不容易和原神的按键冲突。

隐私说明

扩展不联网、不上传任何数据，只读取B站标签页里的视频状态与标题，用来执行播放控制。
