# B站全局媒体控制

在《原神》保持前台、鼠标键盘都在游戏里的时候，用全局快捷键控制 B 站网页攻略视频：

| 功能 | 默认快捷键 |
| --- | --- |
| 播放 / 暂停 | `Ctrl + Shift + 1` |
| 快退 3 秒 | `Ctrl + Shift + 2` |
| 快进 3 秒 | `Ctrl + Shift + 3` |

快捷键由浏览器在后台处理，**不会激活浏览器窗口，也不会让游戏失去焦点**。

> 第一次使用时，请先在 B 站视频页面手动点一次播放。浏览器的自动播放限制会让“从未播放过”的视频无法被脚本直接播放。

---

## 安装（Microsoft Edge）

1. 把 ZIP 解压到一个**固定位置**，例如 `D:\Tools\`。  
   解压后应该能直接看到 `manifest.json`、`background.js` 等文件；不要删除或移动这个文件夹，浏览器会从这里加载扩展。
2. 在 Edge 地址栏输入 `edge://extensions` 并回车。
3. 打开左下角的 **开发人员模式**。
4. 点击 **加载解压缩的扩展**。
5. 选择**包含 `manifest.json` 的那一层文件夹**（名称可能是 `bilibili-media-hotkeys` 或 `B站全局媒体控制-v1.0.0`）。
6. 建议点击工具栏的拼图图标，把 **B站全局媒体控制** 固定到工具栏，方便查看状态。

## 安装（Google Chrome）

步骤相同，只是地址栏改为 `chrome://extensions`。

---

## 使用

1. 在浏览器打开 B 站攻略视频，例如 `https://www.bilibili.com/video/BV...`。
2. 手动点一次播放，确认视频能正常播放。
3. 切回原神，让游戏保持前台。
4. 按快捷键：

   - `Ctrl + Shift + 1`：播放 / 暂停
   - `Ctrl + Shift + 2`：快退 3 秒
   - `Ctrl + Shift + 3`：快进 3 秒

5. 想看当前状态时，点一下扩展图标：弹窗会显示视频标题、播放状态、进度，以及三个测试按钮。

### 多个 B 站标签页

扩展会优先控制**当前激活的 B 站标签页**；如果它是 B 站首页等没有视频的页面，会自动寻找最近使用过的 B 站视频标签页。

---

## 修改快捷键

1. 点扩展图标，点弹窗里的 **修改**；或直接打开：

   - Edge：`edge://extensions/shortcuts`
   - Chrome：`chrome://extensions/shortcuts`

2. 找到 **B站全局媒体控制**，点击快捷键输入框，按下你想要的组合。
3. 建议保留 `Ctrl + Shift + 数字`，不容易和原神的按键冲突。

> 全局快捷键的默认建议值受浏览器限制，只能是 `Ctrl + Shift + 0~9`；在快捷键设置页里可以改成其他组合，但如果和游戏/其他软件冲突，可能失效。

## 常见问题

### 按快捷键没有反应

按顺序检查：

1. **浏览器还开着吗？** 扩展的全局快捷键依赖浏览器进程，关闭 Edge/Chrome 后无效。
2. **B 站视频页还开着吗？** 只对 B 站标签页生效；关掉页面或只开 B 站首页不行。
3. **视频是否手动播放过？** 先点一次播放，再切回游戏。
4. **快捷键是否被占用？** 打开 `edge://extensions/shortcuts`，看三个快捷键是否为空或显示冲突。被其他软件占用时，换一个组合。
5. **刚安装时页面已经开着？** 刷新一次那个 B 站页面，让内容脚本注入。
6. **扩展是否启用？** 在 `edge://extensions` 里确认开关是打开的。

### 会不会把游戏切到后台？

不会。扩展使用的是浏览器的**全局命令**机制，快捷键在浏览器后台触发，扩展只向 B 站标签页发送控制消息，不会调用“激活窗口/切换标签页”的操作。

### 游戏以管理员身份运行时没反应

Windows 的权限隔离（UIPI）会阻止普通权限的浏览器接收全局热键。请优先**正常启动游戏**，不要勾选“以管理员身份运行”；如果游戏必须提权，则需要让浏览器也以管理员身份运行（不推荐日常这样做）。

### 全屏游戏里没反应

先试一次“无边框窗口”模式。少数游戏的全屏独占模式会拦截系统热键；原神一般不受影响。

### 支持哪些页面？

- `www.bilibili.com/video/...`：普通视频
- `www.bilibili.com/bangumi/play/...`：番剧/影视
- 其他 B 站子域名的页面会尝试寻找页面里的主视频

直播页可以播放/暂停，但“快进/快退”取决于直播流是否支持 seek，通常不可用。

### 为什么默认是 3 秒？

按你的需求设置。想改步长：点扩展图标 → **设置** → 修改“快进 / 快退步长”（1–30 秒），保存后立即生效。

### 关闭页面提示

设置页里可以关闭“显示页面提示”。关闭后仍然会正常控制视频，只是不在 B 站页面顶部显示“已暂停/快进 3 秒”的短提示。

## 权限与隐私

扩展只申请以下权限：

- **`storage`**：保存快退/快进步长和提示开关。
- **`scripting`**：在已打开的 B 站标签页里补注入控制脚本。
- **B 站站点权限**：只匹配 `*.bilibili.com`，不会读取其他网站。

扩展**不联网、不上传数据**，只在本地读取 B 站标签页的视频状态和标题，用来执行控制。

---

## 技术原理

- `manifest.json` 里声明了三个 `global: true` 的 `commands` 全局快捷键。
- 浏览器在后台触发命令后，`background.js` 找到最近的 B 站标签页，向内容脚本发送 `toggle / back / forward` 指令。
- `content/player-core.js` 选择 B 站播放器里的主 `<video>`，调用 `play()`、`pause()` 或修改 `currentTime`。
- 没有使用任何会激活窗口的 API，所以游戏焦点不会被抢走。

## 更新

替换文件夹里的文件后，打开 `edge://extensions`，在扩展卡片上点 **重新加载**，然后刷新 B 站页面。
